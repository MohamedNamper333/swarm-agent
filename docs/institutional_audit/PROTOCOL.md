## قواعد مستفادة (تتحدث مع كل ملف)

1. الحزمة الفارغة تقتل الوحدة — افحصها أولاً دائماً (A2).
2. `except: pass` في مسار أمني = ثغرة مؤكدة.
3. أي `datetime.now()` بدون timezone → خلط naive/aware عاجلاً أمآجلاً.
4. التصنيف بالنص الفرعي (`"veto" in text`) = false positives مضمونة.
5. الكتابة على القرص في مسار hot تحتاج throttle + atomicity.
6. fail-closed يكشف أخطاء مخفية فور تطبيقه — اجعل اختبار C2 بعد B مباشرة.
7. الاختبارات توثق العقد — لا تحذف توقعاتها بل وفّرها بمحوّل.
8. baseline الاختبارات يُقاس قبل أول تعديل ويُقارن بعده دائماً.
